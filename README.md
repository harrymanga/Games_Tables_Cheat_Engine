# Games Tablets Cheat Engine

Colección de tablas para Cheat Engine 4.5 para diversos juegos.

## Juegos Incluidos

- **Aska**
- **Factorio**
- **Flood Land**
- **Force Of Nature**
- **Graveyard Keeper**
- **Last Wood**
- **Northgard**
- **Star Bound**
- **Stoneshard**
- **Terminus Zombie Survivors**
- **The Wild Eight**
- **Zelter**

## Plantilla

- **Plantilla_de_Tabla**: Plantilla base para crear nuevas tablas

## Uso

1. Abre Cheat Engine 4.5
2. Carga la tabla del juego deseado (.CT)
3. Selecciona el proceso del juego
4. Activa los trucos deseados

## Nota

Usa estos trucos de forma responsable y solo en juegos single-player.
